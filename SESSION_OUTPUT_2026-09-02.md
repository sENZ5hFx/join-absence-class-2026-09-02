## Primary insight

**Join-Absence Class (JAC).** After the subtractions above, the remaining unknown is not a missing place, not a missing converter, not an insufficient named cause, and not a clock mismatch.

It is this: **two ledgers already share a physical channel; each is independently instrumented; the cartesian product has never been the object of inquiry.**

The experiment that would close the gap is a *join*, not a new instrument.

### Operators inside JAC

1. **Shared-channel occupancy** — a real physical carrier (field, flux, photon budget, sequence database) is already the object of two communities.
2. **Ledger split** — each community has time series, catalogs, or noise models. They do not share a primary key.
3. **Residual-after-spoken-confound** — any honest join must first remove the *spoken* coupling (for geomagnetism: solar storms). The remaining residual is the only thing that could be new.
4. **Public-data runnability** — JAC only counts if the join can be attempted with existing public datasets. If it needs a new satellite, it was undersampling.

### Falsification rule

- If the join has already been published as the object of a paper → JAC is wrong for that pair.
- If performing the join closes the residual → JAC was the right class, and the coupling may be real.
- If performing the join yields a pre-registered null → JAC was the right *question* and the coupling is imaginary. That is a result.
- If more spatial samples at the same cadence close it → undersampling (already claimed).
- If locating the converter closes it → TAC (already claimed).
- If adding more of the named cause closes it → not NCR; JAC does not apply.
- If watching longer closes it without joining ledgers → CIC, not JAC.
